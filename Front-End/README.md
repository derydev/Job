# JobDerv Dashboard Template

Template frontend inspirado na referência visual enviada.

## Executar
Abra `index.html` no navegador ou use a extensão Live Server do VS Code.

## Ficheiros
- index.html
- style.css
- script.js

## Incluído
- Dashboard responsivo
- Sidebar
- Pesquisa de vagas
- Cards de vagas
- Gráfico de candidaturas (Chart.js)
- Gráfico de estados
- Light/Dark mode com localStorage
- Botões de guardar vagas
- Área de automação

Na próxima fase, este frontend pode ser ligado ao backend FastAPI do JobFlow.
